# ConvertAvif
各種画像を最終的にAVIF形式に変換する。

## 概要
ディレクトリ内に含まれる大量の各種画像を一括でAVIF形式の画像に変換する。

## 入力対応形式
- BMP
- PNG(アニメーションも含む)
- JPEG
- GIF(アニメーションも含む)
- TIFF
- WebP

## 出力形式
AVIFのみ。
色空間やビット深度、クオリティは変換時に指定する。

## その他の機能

### ファイルの置き換え
変換時、元のファイルよりファイルサイズが小さくなった場合は、元のファイルを削除して変換後のファイルを残す。
逆に元のファイルより大きくなった場合は、変換後のファイルを削除して元のファイルを残す。

### アーカイブファイル内の探索
アーカイブファイル内も対象とする。
可能であれば、アーカイブファイルの更新で対応するが、無理であれば内容を更新したアーカイブファイルを新規に別名で作成する。
